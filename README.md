# ClearPath

**A beautiful journey toward clarity and freedom.**

## Design Philosophy

This app was crafted with obsessive attention to detail, guided by a simple principle: **design is how it works, not just how it looks.**

Every pixel serves a purpose. Every animation has meaning. Every color choice supports healing.

### Core Design Principles

1. **Empathetic Beauty**
   - Design that understands the emotional weight of this journey
   - Warm, non-judgmental interfaces
   - Colors inspired by nature, growth, and healing

2. **Clarity Above All**
   - No learning curve. Intuitive from first touch.
   - Typography that breathes
   - White space that provides peace

3. **Purposeful Motion**
   - Every animation tells a story of progress
   - Smooth, natural transitions
   - Delightful micro-interactions that celebrate effort

4. **Emotional Intelligence**
   - The Emergency Toolkit is calm, not alarming
   - Progress is celebrated, not just measured
   - Relapses are data, not failures

## Design System

### Colors

**Primary (Sage Green)** - Growth, hope, nature
- Main: `#4A9D73`
- Represents healing and forward movement

**Secondary (Sky Blue)** - Calm, trust, clarity
- Main: `#4A8DB3`
- Provides emotional balance

**Accent (Warm Coral)** - Energy, vitality, warmth
- Main: `#FF8766`
- Sparks motivation

### Typography

System fonts optimized for readability and warmth.
- Modular scale (1.25 ratio)
- Generous line heights
- Thoughtful letter spacing

### Spacing

4px grid system for pixel-perfect alignment.
Every element breathes. Nothing feels cramped.

### Components

Each component is crafted to feel both native and special:
- **Buttons**: Tactile, responsive, gradient-enhanced
- **Cards**: Elevated with subtle shadows, perfect padding
- **Inputs**: Smooth focus transitions, encouraging
- **Typography**: Pre-styled for consistency and beauty

## Key Screens

### Welcome Screen
The first impression. Sets the emotional tone: hopeful, warm, understanding.
- Animated seed growing into sprout
- Orchestrated entrance animations
- Clear value proposition

### Onboarding Flow
A thoughtful journey setup experience.
- Progressive disclosure
- Non-judgmental questions
- Beautiful option cards with tactile feedback

### Home Screen
The heart of the app. Daily inspiration and progress.
- Growing tree visualization
- Quick stats at a glance
- Always-accessible emergency support
- Motivational elements

### Emergency Toolkit
When someone needs help NOW.
- Immediately calming design
- Breathing exercise with animated circle
- Quick distraction activities
- Personal "why" reminders
- Zero judgment, pure support

## Running the App

```bash
npm install
npm start
```

Then:
- Press `i` for iOS simulator
- Press `a` for Android emulator
- Scan QR code with Expo Go for physical device
